Auto-Calibration (per key)

This runs the MPR121's built-in auto-configuration, which finds the right charge current & time (CDC/CDT) for every key individually so each pad charges to the same target level — compensating for different pad sizes and wiring lengths. The discovered values are read back, saved to flash, and (when frozen) re-applied on every boot.

Stand off all keys while calibrating — it measures the untouched (baseline) charge level.

180 higher = stronger signal / bigger touch delta (too high may fail → out-of-range)
Tip: select a single misbehaving key to re-tune just that one.

Calibrating a subset always freezes those keys (adaptive auto-config would re-tune every key and undo a per-key result).

Interactive Threshold Calibration

Step on each key when prompted. This measures how strongly each key responds to a real foot and how much the neighbouring keys are pushed up (cross-talk), then sets per-key touch / release thresholds so each key registers reliably while the others stay off.

Run the CDC/CDT auto-calibration above first. It measures the keys you selected in the grid (select All for the best cross-talk protection).

Signal Strength (boost touch sensitivity)

A bigger touch delta (the drop below baseline) comes from charging the pad harder. Increase charge current first, then charge time, until the filtered value sits high (≈ 200–250 on the Debug graph) without flat-lining at 1023. To use these you must turn Auto-Config OFF (set it to 0 below) — otherwise the chip overrides them at startup.

Start over (clean reset)

Use this when the piano misbehaves in a new place. It clears the saved per-key charge and thresholds, switches the chips back to adaptive auto-config, and reboots so they re-calibrate fresh on the current floor. Afterwards, run Calibrate → Auto-Calibration, then the Threshold wizard.

Why doesn't it work? — troubleshooting

It connects, but keys do nothing / Debug graphs are frozen
  • Check the link first. Start Live diagnostics above. If frames/s = 0 while it says Connected, it's the WiFi, not the pads.
  • Pick a clear channel. Settings → System → WiFi → Scan channels, use the recommended one, Save WiFi, reboot. Busy 2.4 GHz (libraries, offices) jams the default channel.
  • Move the laptop next to the device and keep the antenna clear of metal.
  • Are the chips alive? System → Device Info → MPR121 #0/#1 must say Connected. If not, reseat the I²C wires (SDA/SCL/3V3/GND) and the address pins.
Frames arrive but touch barely moves Δ (weak / erratic)
  • Reset & recalibrate (button at the top) — old calibration from another room can rail the readings. Then Auto-Calibration → Threshold wizard.
  • Boost the signal: Configuration → raise charge current (CDC) then charge time (CDT), or just let Auto-Calibration set them.
  • Grounding/earth: capacitive touch needs an earth reference. Try a different power source, or run a wire from the device GND to a real earth point. Bare/thin-sock feet couple far better than thick shoes.
  • Floor matters: thick carpet/underlay or a raised floor weakens coupling. A grounded foil/strip under or beside the pads helps.
Several keys fire when I press one (cross-talk)
  • Run the Threshold wizard (it sets per-key thresholds above each key's cross-talk) and check the Monitor tab while pressing.
  • Raise the wizard's Trigger point; lower the Release threshold % only as far as the “release near cross-talk” warning allows.
  • Increase pad spacing or add a grounded strip between pads.
Noticeable delay / lag
  • Clear WiFi channel (scan), laptop close, device on a good power supply.
  • Configuration → lower the filter samples (FFI/SFI) and sample interval (ESI) for a snappier sensor (re-run the wizard after — noisier).
  • SoundFont player: drop the audio buffer to 512.
It won't connect at all
  • Join the FloorPiano WiFi (password piano1234) and open http://192.168.4.1.
  • Power-cycle the device; watch the System tab for the AP IP.
  • If you set a “Join SSID”, the AP follows that network's channel — remove it for a standalone setup.
No sound
  • Piano tab: press ▶ Start playing (polling is off until you do), which also unlocks the browser audio.
  • Using the SoundFont player? Make sure a .sf2 is loaded and the buffer isn't muted.
